
# Day 060 — Goldify ✨

### Premium Gold Analysis & Financial Intelligence Platform

Goldify is a modern, responsive, multi-page finance website concept inspired by premium gold-analysis platforms. Designed with a cinematic visual experience, elegant layouts, and interactive market visualizations, Goldify combines sophisticated aesthetics with a seamless user experience.

The platform showcases a conceptual financial intelligence product focused on gold market insights, analytical tools, pricing plans, and financial information.

## ✨ Features

- Cinematic and visually engaging homepage
- Responsive multi-page website
- CSS-based gold market visualizations
- Interactive feature dashboards
- Dedicated pricing page with plan comparison
- Editorial insights and market perspectives
- Dedicated contact and enquiry page
- Accessible and responsive navigation
- Smooth animations and modern UI interactions
- Browser-based form validation
- Premium design with a sophisticated visual identity

## 📄 Pages

| Page | Description |
|---|---|
| `index.html` | Cinematic homepage and product overview |
| `about.html` | Brand purpose and product principles |
| `features.html` | Platform capabilities and analytical workflow |
| `pricing.html` | Illustrative pricing plans and comparison |
| `insights.html` | Editorial content and sample market perspectives |
| `contact.html` | Dedicated enquiry form |

## 🛠️ Technologies Used

- Responsive Web Design
- CSS Market Visualizations

## 🚀 Run Locally

Navigate to the repository root:

```bash
cd ~/Desktop/Projects/thecore-100-days-web
```

Start the local server:

```bash
python3 -m http.server 8080
```

Open the website in your browser:

```text
http://localhost:8080/phase-3-complete-websites/site/day-060-goldify/
```

No installation or build process is required.

## ⚠️ Disclaimer

Goldify is a frontend demonstration project.

All market figures, pricing plans, integrations, and financial insights are illustrative sample content.

This website does not provide financial advice, connect to live market data, or execute trades. Contact and newsletter forms validate in the browser but do not transmit data until a backend service is configured.
